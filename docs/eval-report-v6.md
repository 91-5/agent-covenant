## 4. 结论

1. **影子门（§12 D4）：未达标（事实）**——真实轮次判级一致率 A 0.6058 / B 0.6577，远低于 95%；主判定切换不具备讨论资格。结构化断言 DSL 的「编译一致率」在真实自由文本断言面上远低于合成样例的水平（合成试运行 0.9848 的机械正确性 ≠ 真实编译一致率——ADV-4 边界得到实测确认）。
2. 一致率缺口的主要构成是语义面（123/114 条）：编译器按断言语义选取的判据，其机械执行结果与主轨判级在约四成的可比对上不一致——DSL 单谓词表达力（对抗问 4 的宽化/窄化风险）与编译裁量是下一轮设计输入，本卡不改判定。
3. 主轨复制发现：同断言面重放完整复制第五轮判级与解盲读数——v1.5 仪器管线确定性得到端到端验证。
4. M1/M2：在预注册条件下未检出达到最小效应的差异（与第五轮逐字一致）。
