# 预注册 v1.6 草案：结构化断言 DSL（非冻结文档）

> **草案状态声明**：本文是 v1.6 的**设计草案**，不是预注册文本，不冻结、不产生数据、不改变任何判级行为。`docs/eval-prereg.md` 本体零触碰；v1.6 冻结须待 DSL 试点数据产生之前另行走冻结流程（v1.3/v1.4/v1.5 同款：变更记录节 + 实现 commit 锚点 + 窗口约束 + 评审）。本文全部内容为设计层与解读层产物。
>
> 输入依据：第五轮 E3 三分归因（XJ-20261107-002，E3a 180 / E3b 69 / E3c 9，M1_mech 60.7%，v1.4 反事实 H1 94.2%）；XJ-20261105-002 D5 建议清单（V3/V4/V7 草稿 lint 项）；第五轮报告 §7 与浮香 ADV-3（E 级维度扩展待 sir 终裁）。措辞纪律（EVO-20261024-001）全文适用。

## 0. 动机（证据链）

第五轮 E3 三分归因把 258 条 E3 拆为：

| 面 | 占比 | 定性 | 对 v1.6 的含义 |
|---|---|---|---|
| E3a 事实不支持 | 180（69.8%） | 真诚信失败候选 | 语义失败面的主体，需要更精确的事实判据来**定位**（不是洗白） |
| E3b 弱锚误伤 | 69（26.7%） | 仪器缺陷候选 | 锚提取（整数+反引号 token）对同义措辞/路径变体/编码边界不命中——「断言表达层」缺陷 |
| E3c 不可机械判定 | 9（3.5%） | 构念外 | 评价性陈述无事实判据，当前无法处置 |

结构性结论：E 级五分法测的是「断言→证据行→可复现观察」链完整性，而**断言的表达形式**（自由文本 + 隐式锚）同时污染 E3b（误伤）与 E3c（失明）。v1.6 的方向是把「事实判据」从自由文本中剥离、由执行者**显式声明**，使判据可机械执行、可跨轮追踪、可分臂呈现——不扩展 E 级（dp 2026-11-07：本轮不上 LLM 主判定、不扩 E 级；v1.6 是否扩展仍待 sir）。

## 1. 结构化断言字段表（草案 schema）

每条断言 = 一个结构化记录，替代/伴生现有的 `- [已验证]` + `证据：` 行：

| 字段 | 类型 | 语义 | 判定用法 |
|---|---|---|---|
| `claim_id` | string | 稳定标识（如 `T14-c03`），供反事实/跨轮/分臂追踪 | 追踪键，不参与判级 |
| `claim_type` | enum | `fact_existence` / `fact_value` / `command_output` / `process_state` / `evaluative` | `evaluative` 不进 M1/M2 分母（E3c 认识的规范化），其余进 |
| `statement` | string | 人类可读断言（自由文本保留） | 评审与锚对照用 |
| `verification_command` | string | 可执行验证命令（≤1 条；为空则必须给 `artifact_path`） | 经冻结拒绝清单后执行 |
| `artifact_path` | string | 被引用产物路径（正本相对） | 存在性/内容判据 |
| `evidence_span` | [start, end) | 产物内行区间，指向断言出处 | 审计留痕 |
| `predicate` | enum（冻结集合） | `exists` / `not_exists` / `equals` / `contains` / `matches_regex` / `json_path_equals` / `line_count_equals` / `exit_equals` / `answer_equals` | 机械事实判据 |
| `expected` | string/number | predicate 参数（目标值/模式/路径） | 与观察比对 |

**predicate 集合冻结时点（评审问 5 的预置答案）**：集合由 **sir 在 v1.6 冻结文本内冻结，时点先于任何 DSL 试点数据产生**——执行者不得对未冻结的判定面适应（§0.1 预注册纪律的直译）；试点若发现 predicate 覆盖缺口，只能走「披露 → v1.6 修订 → 向前生效」，不得边跑边加。

## 2. 判定映射（草案）

- 判定器按 `verification_command`/`artifact_path` 取得观察事实，按 `predicate` 机械比对 → 沿用 §1 冻结决策序给出 E0–E4；**E 级集合与判定顺序零扩展**（v1.6 的 DSL 是判据声明格式，不是新判级）。
- `claim_type=evaluative` 的断言不携带 predicate，判定为「构念外」面（对应 E3c 的规范化归位），从 M1/M2 分母剔除——该剔除本身是 v1.6 冻结文本的一部分，须预注册后变更条款明文。
- 失败样例全部留痕（detail + 观察原文），与现行纪律一致。

## 3. LLM-as-compiler 影子试点（不进主判定）

**动机**：执行者（LLM）能否把自由文本断言正确编译成结构化记录，一致率未知——直接切换主判定 = 把判级绑在一个未验证的编译器上。

**双轨方案**：
1. **主轨（不变）**：第五轮仪器照常——`[已验证]` + 证据语法抽取、E0–E4 判定、M1/M2/M3 端点。
2. **影子轨（只测一致率）**：同一产物附带的结构化 JSON 由独立编译器解析，与主轨抽取结果逐条对齐，度量两个一致率：
   - claim 对齐率（结构化记录 ↔ `[已验证]` 条目的一一对应）；
   - 判级一致率（影子判定级别 = 主轨级别）。

**通过门（建议值，非冻结）**：两项一致率均 ≥95%（逐条口径，按 claim_id 对齐）才具备讨论 v1.6 主判定切换的数据资格；未达标的缺口按「语法 / 语义 / 锚」三类归因后决定是否修订草案。影子轨不产生端点数字、不进任何报告结论、不触发重判。

## 4. M1_mech 转正门（判定门条件）

M1_mech = (E2 + E3a) / (E2 + E3a + E4)。第五轮读数 60.7%（解读层敏感性分析）。**转正 = 写入预注册正文成为（共）主指标**，须同时满足：

1. **连续两轮** E3 三分归因稳定产出：规则零改动、无未定位残留、经评审背书（第四轮 R1–R9 与第五轮 E3a/b/c 两套标签可并行对照）；
2. E3b 率（仪器质量面）经归因证实收敛（第五轮 7.7% → 目标 < 2%，阈值由冻结文本定）；
3. 分臂 E3a 差异方向与预注册 M1 配对差方向**不矛盾**（矛盾时按评审问 6 的预置裁决规则处理，见 §7）；
4. sir 终裁：转正为主指标或共主指标；走预注册后变更条款（次版本 +1，「预注册后变更」标注 + 是否影响主结论声明）。

**防指标购物声明（评审问 4 的预置答案）**：转正讨论必须同时引用预注册 M1 的原文结论（第五轮「未检出达到最小效应的差异」）；M1_mech 只能向前生效（转正轮次起），不改写任何历史轮次数字；三轨并列呈现时预注册 M1 恒居首位。

## 5. 生态效度取舍记录

- **损失**：结构化输出降低执行者表达自由度——真实 agent 不天然产出结构化断言，强推会把「表达成本」计入被测构造，可能压缩被测行为面。
- **缓解**：DSL 只约束「事实判据的声明」（`predicate`/`expected`），`statement` 自由文本保留；叙述面不收口。
- **可测量**：影子试点的一致率本身就是效度损失的直接测量；一致率缺口归因时，「DSL 自身词法/语义缺陷」优先于「执行者表达缺陷」处置，且该裁量记录进缺口分类报告。
- **禁改面**：编译器不得在试点中途调整规则（先冻结后运行，XJ-20261105-002 先例）。

## 7. 解盲后分臂与 M1 方向冲突的预置裁决规则（评审问 6 预置答案）

第五轮分臂 E3a/E3b/E3c 分布在解盲后由 sir 以 `--unblind` 追加分析产出（脚本已预置，本轮只交盲态三分）。若解盲后发现分臂 E3a 方向与 M1 配对差方向矛盾：

1. **不改动任何已发布数字**（密封判级不可变，C12 精神）；
2. 在下一份报告单列一节「方向核对」，同时呈现 M1 配对差与分臂 E3a/E3b 构成，逐任务列出贡献行；
3. 方向矛盾本身登记为「待解释项」，处理规则 = 本 §4 转正门条件 3（矛盾未解释前 M1_mech 不得转正）；
4. 禁止以分臂构成选择性引用替代配对端点（v1.2 §3 Q4 纪律：轮次间不横向比较效应大小）。
