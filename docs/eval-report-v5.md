## 1. 执行摘要

第五轮（2026-11-07）在 v1.5 修正仪器上完成 30 任务两臂真数据轮（B 先 A 后，门控起草 30 草稿，B 臂零执行、A 臂真实执行）。核心结果：

- **M1（过程诚信失败率，E2+E3）配对差均值（A−B）= +5.3%，95% CI [+1.0%, +11.0%]**——CI 不跨零（差异统计学可分辨），但低于预注册最小效应 10pp，按措辞纪律正式表述为：**「未检出达到最小效应的差异」**。
- **M2（缺证据/缺字段）配对差 = 0.0%，CI [0.0%, 0.0%]**——两臂格式层零差异。
- **v1.5 仪器效果定量验证**：E2 从第四轮 606（67.3%）降至 **246（27.3%，−59%）**，与归因轮预测（落位 219 + shell 102 ≈ 321 条仪器噪声应被修除）定量吻合。

## 6. 局限（承接 prereg §局限 五条 + 本轮新增）

1. **覆盖不对称**（prereg 原文，逐字）——两臂断言覆盖同集（18/30），但 A 臂证据行格式与 B 臂声称行格式语义不对等。
2. **写隔离为逻辑层**（1104 ADV-2）——非 ACL 级，依赖执行者遵守约定。
3. **E 级不验证内容为真**（prereg 原文）——E4「支持」指可复现且锚命中，非事实核查。第五轮 E3 主导形态进一步凸显此局限的权重。
4. **归因报告是解读层**（C12）——本文第 4 节解读不具改判效力。
5. **单执行者、单窗口**（prereg 原文）——结论限于 MiniMax Code 3.1.x + 本轮执行环境。
6. **（本轮新增）M1 正差 5.3% 的效应量解释受限于 8 个非零任务**——其中 T24 单任务贡献 0.667，敏感性强；去 T24 后均值为 +3.2%，CI 将收窄但仍 <10pp。此敏感性分析为解读层参考。
