## 0. 结论边界（先读这条）

**本轮不构成门禁有效性的对照证据。** 它证明的是**测量仪器与管线在真实研究数据上按设计工作**，以及**预注册 v1.0.0 的条件设计存在结构性缺陷**。任何把本轮数字引用为「门禁降低幻觉/减少假验证」的说法，都是对本报告的错误引用。

## 3. 为什么 M2 = −100.0% 不是效力证据

条件 B 按 v1.0.0 定义「不要求证据行」，其 90 条断言**按构造全部落 E0**（无证据行）；条件 A 按证据行纪律产出，90 条全部落 E4（证据支持）。因此：

> M2 的 −100pp 是**条件定义的机械后果**——「要求证据行」自然产生「有证据行」的产出。它测量了条件定义本身，没有测量门禁流程在真实 agent 工作中的效力。

同理 **M1 结构性失效**：M1 的分母是「声称有证据的断言」（E2+E3+E4），B 臂按构造零条 → 分母为 0 → 全部任务排除 → 配对数 0。**预注册的主指标在 v1.0.0 条件下不可计算。**

根因归并（三条，均须写进 v1.1 修订）：
1. **B 臂退化（degenerate arm）**：真正的对照应是「同样会声称已验证、但没有独立评审/门禁兜底」的产出。
2. **主/次指标选择与条件定义不匹配**：M1 需要两臂都有带证据的断言。
3. **同执行者 + 知晓规则**：同一执行者按条件自律 ⇒ A 恒完美、B 恒空白（dp 大脑陷阱 #2「指标变目标」的具体形态）。

### 4.2 判定器抓到执行者的两次真实缺陷

| 场景 | 缺陷 | 判定 |
|---|---|---|
| T02 首版证据 | 证据命令中的路径转义错误 → 命令复现失败 | **E2 不可复现**（正确 fail-closed） |

## 6. 局限性（五条，原文必载）

1. 样本小：30 任务 × 2 条件 × 3 重复远低于能精确估计小效应的样本量，置信区间宽，未达最小效应不等于无差异。
2. 任务构造：任务由团队自建并自标注标准答案，构造偏差可能同时影响两个条件，配对设计只能缓解、不能消除。
3. 代理指标：E0-E4 判定测的是过程诚信（断言-证据链完整性），不是知识正确性；harness 不验证断言内容为真。
4. 单 adjudicator：盲化判定由唯一评审员承担，其系统偏好无法在本设计内交叉验证。
5. 同执行者：两个条件由同一执行者完成，执行者对假设的预期可能泄漏到产出中，只能靠盲化与负对照部分约束。

**本轮追加第六条（v1.0.0 设计缺陷，已修订入 v1.1）：** 条件 B 为退化臂（按定义不产生带证据断言），导致主指标 M1 不可计算、次指标 M2 变成条件定义的同义反复。本轮不构成有效性证据的直接原因即在此。
