## R1 · 影子轨观测面与主轨对齐（修编译器）

**结论**：影子轨必须以**主轨的观测面**执行判据——C10 重建工作区（cwd=workspace）、`artifact_path` 按 workspace→root 兜底解析、证据行 ref 路径按主轨同一套解析规则取值。

## R2 · 命题层级对齐：先定义「什么算支持」（修判级器）

**结论**：主轨 E4 与影子判据在 99 条上**测的不是同一个命题**。在把一致率当作「影子轨能否替代主轨」的证据之前，必须先冻结「支持」的定义：主轨 E4 目前包含「无语义锚的机械通过」（只证明证据行自洽/可复现，不证明断言语义为真），而影子判据直接问「断言内容是否成立」。两者不是同义反复。

**依据（D-00 逐条）**：

- **S1 判证据行 vs 判产物（30 条）** —— 主轨 E2 依据是「退出码不符：证据声称 exit=255，实际 exit=0」「声称输出未复现」「锚未命中」：主轨问**执行者自报的证据行是否自洽**；影子判据问**产物存在性/内容**。
- **S2 机械 E4 vs 语义判据（42 条）** —— 主轨 E4 依据是「ref 存在且可读（无语义锚，仅机械复核通过）」或「命令已复现…已命中」：**未核验断言语义**；影子判据直接问内容 → 在被观测文件上确不成立。典型：断言「第 4 节标题词为『承诺生命周期（Commitment Lifecycle）』」对 `PROTOCOL.md` 求包含——轮七判定时点（4fcd097）的 `PROTOCOL.md` 第 4 节是 `## 4. Artifacts`。
- **S3 复现失败命令 vs 问语义（3 条）** —— 执行者自报的 `git log … | ForEach-Object {…}` 本身以 exit=255 失败（cmd.exe 不识别 `ForEach-Object`），主轨只核「自报输出与真实输出逐字相同」→ 相符 → 判支持；影子问「类型前缀是不是 `chore`」→ 不成立。
- **轮六 51 条**（D-02 §4.2 逐条表）同签名：**24 条**判据在执行者工作区成立、仓库根不成立（观测面分歧 → R1）；**27 条**为命题层级错位（其中 24 条主轨判证据行/锚，3 条为 `ForEach-Object` 在 cmd.exe 失败仍被主轨判 E4 的极端形态，与轮七 S3 同签名）。

**结论**：**不建议**任何针对 `truly_missing` 的「修复」。轮七 24 条 truly_missing（A 3 / B 21）是执行者真实差异/潜在造假信号，只应计数与披露，**不得通过修锚清单或放宽判据转为一致**（卡面「不洗白」红线）。

## R5 · 影子判据结果列的语义更正（修编译器：数据契约）

**结论**：`records-*-graded.jsonl` 的 `predicate_ok` 列**名不副实**——它存的是**与主轨的一致性旗标**（与 `alignment-split.json` 的 `consistent_flags` 逐条同值），而非影子判据的原始机械结果。D-00 若直接取用该列，159 条里将有相当一部分被填反。**该列必须改名或改值**，否则下一张卡会重蹈本卡的判定成本。

**依据**：D-00 核定过程（详见 `docs/d00-mismatch-analysis.md` §2）：以冻结编译器 `tools/eval/dsl_compiler.py` 在同观察根重算后，原始结果与冻结一致旗标自洽（A 309/309、B 48/48），而与该列大量不符。

**ledger 证据**：台账全部 159 条的 `shadow_predicate_ok` 字段（取自冻结编译器重算值），可与 `records-*-graded.jsonl` 的同名列逐条对照；机制分组见 `ledger:` `P028-c03`、`P052-c03`、`P109-c03`、`P135-c03`（I1，raw 与 graded 列直接相反的典型例）等 159 条全覆盖。

**预注册风险**：

1. 该列改名属**数据契约变更**，影响下游所有消费者；须先冻结新列名与语义再改产物生成器。
2. 更正后，任何历史轮次基于该列的结论都需**重新核对**——本卡已核，轮六/轮七报告本身用的是 `alignment-split.json`（正确来源），结论不受影响。

## 与 §15（D4）的关系

R2 的收益无法在旧数据上量化，因为「一致」的定义本身在争议中。`docs/prereg-s15-compilation-quality.md` 给出**与判级语义解耦**的编译质量度量（编译保真度 + 观测面一致性 + 命题对齐度），使「编译器选得对不对」可以在**不动主轨判级**的前提下先被独立度量。本 Memo 建议：**先立 §15 度量，再谈 R2**。
