## Context

轮九结论（双卡 PASS，浮香独立复核）：R1 影子观测面对齐后，**A 臂判级一致率不升反降**——pre-R1 180/309（0.5825）→ post-R1 129/309（0.4175）。机制由 E4 双向消融坐实：pre-R1 时影子判据在仓库根静默失败 → 与主轨「不支持」同向 → **系统性伪一致**，pre-R1 读数被高估。E7 已修根因（fail-fast 默认开启 + 5 类预注册 ERROR 分类：FILE_NOT_FOUND / CWD_MISMATCH / PARSE_FAIL / TIMEOUT / SILENT_FALLBACK），严格口径 A 臂 108/288（21 条 ERROR 显式化）。

**门重设计的合法性前提（dp 大脑裁定，钉入卡）**：改门的唯一合法理由是「旧指标测的不是声称要测的东西」（分母污染 + 从未可达），**不是**「旧门让影子过不了」——后者属 HARKing，整轮作废。旧门（95% 单一致率）的两个事实缺陷：
1. **分母污染**：静默失败条目被塌缩成「不支持」计入分母，是分母污染不是能力下降；
2. **从来不是实测可达门**：pre-R1 的 0.5825 同样远低于 95%。

**council 裁定**：95% 单一致率门在当前定义下不可过，应转向双指标门；且**主轨自身 M1 效应弱（5.8%［1.7,11.2］）、判定可复现性从未被验证**——影子轨对齐一个自身判定噪声大的主轨，95% 对齐的上限受主轨可复现性约束。**门的设计前提「主轨判定稳定可复现」从未被验证过，这比 0.4175 更该写进结论。**

**本卡的核心结构**：先测天花板（Gate 0 主轨信度），再按天花板定门（盲态冻结），最后测影子轨。**顺序不可交换**——先看影子数据再定门即过拟合。

## 约束（纪律）

- **产物落点**：`run-dir-r10/`、`shadow-r10/`、`out/` 为执行产物，走 custody 不入 repo（`.gitignore` 已覆盖 `run-dir/`、`dryrun/` 类路径，本轮路径名须自行确认是否被覆盖，未覆盖者须在 D0 同步补 `.gitignore`）。
- **门值盲态冻结（dp 大脑裁定，钉入卡）**：**禁止**「先实测影子分布再定门」。门值只能由 `R_main`（Gate 0，与影子数据独立）经 `M_C = floor_to_5pct(min(0.95, R_main − 0.05))` 推导，且冻结者对 C 值盲。**门重设计只许一次**——本卡 §17 之后不得再改门定义。
- **Gate 0 阻断前置（钉入卡）**：`R_main < 0.90` → 记「主轨不可复现，影子对齐无意义」，**整体挂起转主轨稳定化**，本轮不得报告影子门结论。
- **SILENT_FALLBACK 单列（钉入卡）**：可判定率必须把 SILENT_FALLBACK 单独计数并列出，不得混入其他 ERROR 类或折叠——R1 前的 0.5825 正是 fallback 注水来的，这是防注水的关键机制。
- **可判定性操作化（钉入卡）**：可判定 = `exit == 0` ∧ 输出可解析 ∧ 未落 5 类预注册 ERROR。三者缺一即不可判定。
- **金标准 60 条双盲**：标注者独立于判级结果；`A_shadow ≥ A_main − 0.05` 为**方向判据**（影子不劣于主轨），不作为分层硬门（样本量噪声 + 多重比较，分层仅作诊断）。
- **影子轨定位声明（钉入卡）**：影子轨定位为**「预筛」非「替代」**（主轨 M1 未达最小效应，替代标准过高）；预筛分支门槛 `min(0.85, R_main − 0.10)`。报告不得表述为「影子轨可替代主轨」。
- **红区零触碰**：`tools/eval/judge.py`、`tools/eval/extract.py`、`tools/eval/blind.py`、`tools/eval/report.py`、`tools/eval/stats.py`、`tools/eval/study_runner.py`、`tools/eval/seal_run.py`、`tools/eval/gate.py`、`tools/lint_cards.py`、`verdicts/`、`.eval-sealed/`、`docs/eval-prereg.md` 的 §0–§16 冻结文本。
