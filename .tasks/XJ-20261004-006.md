## Deliverables

### D1 —— `gate.py`：R3 接线（**最重要**）

`_check_independence` 现在：

```python
def _check_independence(data, allow_nonindependent):
    if data.get("independent") is True:
        return []
    ...
```

**改为**：`self_signed is True` 时，**该 verdict 不得被当作独立权威**——
即按 `independent: false` 处理，走同一条 `NOT_INDEPENDENT` 路径
（`--allow-nonindependent` 仍可放行，保持既有语义）。

**同时**：`self_signed` 与 `independent` **互相矛盾时**（`self_signed: true` 且
`independent: true`）必须报错，而不是静默按其中一个算。**这条是本卡的核心**——
它让「自签但标 independent」无法隐身。

### D2 —— `gate.py`：§6.1 valid-authority bar 读 `self_signed`（R3 后半）

`_successor_candidates` / `_superseded_by` 判定「later verdict 是否够格当 successor」时，
**必须把 `self_signed: true` 视同 `independent: false`**。
否则自签 verdict 仍能退役别人的 finding——那正是 B2 指出、ADR 已禁止的行为。

### D3 —— `lint_cards.py`：`unblocks` 的**格式**校验

新增校验（rule code 自拟，建议 `UNBLOCKS_MALFORMED`）：

- `unblocks` 若存在，必须是**非空字符串**或**非空字符串列表**；
- 每个元素须匹配 `^<NS>-\d{8}-\d{3}\.[A-Za-z]\d+$`
  （即 `<卡id>.<条件id>`，如 `XJ-20261004-004.C1`）；
- 元素**不得指向自己的 id**（`XJ-20261004-006.C1` 出现在 `XJ-20261004-006` 的 verdict 里 → 错）。

### D4 —— `lint_cards.py`：**重复闭合**警告（§6.3 的 known hazard）

同一 `unblocks` 值被**两张以上** verdict 声称 → 发 **WARN**（建议 code
`DUPLICATE_UNBLOCKS`）。**按 §6.3 定的是 warn 不是 error**——仲裁延后到本卡之后，
现在只报警不拦截。

### D5 —— `tests/`：R4 的**两条**断言（§6.3 明确要求「一方向一条」）

- **正例**：某 verdict 带 `unblocks`，其 artifact 无 later verdict →
  该文件的 `STALE` finding **照常报出**（闭合不洗白新鲜度）；
- **反例**：`unblocks` **永不**产生 `SUPERSEDED`（任何排布下）。

### D6 —— `templates/verdict.json`：补字段说明

模板补 `unblocks` / `self_signed` 的可选注释，与 §4.5 一致（模板是给人抄的，
字段不在模板里，人就不会写）。
