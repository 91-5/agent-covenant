## ⚠️ 核心设计：正则枚举「状态」会系统性漏掉散文

`XJ-20261013-003` 的第一版扫描只匹配 `IN_REVIEW|OPEN|…` 枚举值，**漏掉了 7 张中的 2 张**——它们写的是英文散文：

```
（示例段落。刻意**不**写成 `## Status`：该标题会被 `_section_body` 当成本卡真实的 Status 段取走，使本卡被误判为仍活跃、继续占着 `tools/lint_cards.py` 等三个文件。真实段落名见本卡末尾的 `## Status`。）

Awaiting independent review.
```

**"状态"不只有枚举值一种写法。** 所以本规则**不复刻那种正则**，改为**复用 `_is_active()`**——「仍是开放态」的定义完全交给那个已有函数，它判 True 就意味着开放，**散文天然被覆盖**。`TestStatusDrift` 里有三个用例专门锁这件事：枚举态、散文态、无 Status 段。
