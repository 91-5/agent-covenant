## Context

轮六真数据影子轨双一致率远低于 95% 门槛（D4 门）：A 臂对齐 1.00 / 判级一致率 0.6058，B 臂 1.00 / 0.6577。失配构成（A 臂 312 条可比对）：semantic 123 条（39%）、eval 78 条（25%）、anchor 60 条（19%）、syntax 0 条。

**口径修正（council D-00，钉入卡）**：semantic 123 = 判级不一致**全集**，eval 78 + anchor 60 是可重叠原因标签（15 兼有），算术自洽（123 = 78+60−15）。轮七收益估算若按 `123+78+60` 相加，会重复计约 78~138 条。本轮卡必须把「判级对分母」与「失配原因标签」分离登记，51 条未归类项（312−261=51，占 16.3%）列为 D-00 待查。

**三桶定性（council）**：
- **semantic 123 = 仪器缺口**（影子 DSL 的 frozen enum 无 command_output 类 predicate，编译即报 `predicate not in frozen enum: None`，属"仪器无法表达"而非"执行者行为不同"）
- **eval 78 = 仪器缺口为主 + fallback 语义可修**（enum 缺口触发 fallback；fallback 在无合法 predicate 时给了默认判级，与主轨不一致。需分诊：多少条本可被新 predicate 消解、多少条是 fallback 逻辑本身错）
- **anchor 60 = 混合，唯一可能含真实差异的桶**：(a) artifact 实际存在但锚清单生成规则漏收 → 仪器缺口；(b) artifact 根本不存在 → 执行者真实差异/造假信号。invalid_rate=0 不排除 anchor 缺失。**把真实差异也"修"成一致，等于把造假信号洗白——anchor 分诊必须 `exists_but_unlisted` vs `truly_missing` 分别计数**

**B 臂不对称（council，钉入卡）**：B 臂命令字段设计性不可执行，新 `command_*` predicate 在 B 臂只能落 `not_applicable` 结构性标记，B 臂不享受可执行 predicate 的收益，只享受 anchor 修复和 fallback 修正。因此轮七后 A/B 一致率差距可能**扩大**而非缩小（推断）。这不是缺陷，是冻结设计的必然——但它意味着"双一致率 ≥95%"在 B 臂需要一个预注册的 `not_applicable` 处理规则，否则 B 臂永远过不了门槛。**该规则列为轮七卡前置交付物（见 Acceptance V6）。**

轮七修订范围（council 已给出，钉入卡）：
1. frozen enum 加 4 条 command_output predicate（P1–P4：`command_exit_code` / `command_stdout_contains` / `command_stdout_regex` / `command_artifact_created`）→ 预期消解 semantic 的 70–85%（+86~105 条 → 一致率 0.88–0.94）
2. fallback 语义改判级器（无合法 predicate → 显式标 `uncompilable`，不硬判）
3. 锚清单更新 pass 进 D0（48 条滞后锚回填）
4. 金标准集 30 条 + 判级器校准报告（P0）

## 约束（纪律）

- **预注册纪律（council，钉入卡）**：predicate 修订必须先冻结设计（文件 hash 入卡）再 off-line 回放再跑真数据，预期消解映射表预注册；顺序错了（先回放调 predicate 再冻结）就是过拟合，卡里明文禁止。
- **不洗白（council，钉入卡）**：anchor 桶中 `truly_missing` 部分是执行者真实差异/造假信号，**不得**通过修锚清单转成一致——把真实差异也"修"成一致，等于把造假信号洗白。锚分诊必须 `exists_but_unlisted` vs `truly_missing` 分别计数。
- **B 臂 not_applicable 规则预注册（council，钉入卡）**：B 臂命令字段设计性不可执行，`command_*` predicate 在 B 臂全部落 `not_applicable` 结构性标记，双一致率门槛对 B 臂的适用性单独声明（预注册，见 D6）。
- **红区**：`judge.py`、`blind.py`、`report.py`、`stats.py`、`study_runner.py`、`seal_run.py`、`gate.py`、`lint_cards.py`、`verdicts/`、`.eval-sealed/` 零触碰。
- **金标准集**：30 条人工标注三元组，判级器校准报告每轮更新，不得参照判级结果标注（预注册纪律）。
- **C12**：不重判轮六历史轮次；轮七只对新增数据开口。
