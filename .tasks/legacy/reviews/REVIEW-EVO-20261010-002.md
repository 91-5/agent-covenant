## 三处重点复核

### ① 「报告而非丢弃」的初版 bug 修正 —— **已堵住漏报，独立核实成立**

作者自曝初版写成 `if paths: 用 paths / else: 报全部`，导致"既有合法路径又有散文"的卡（`XJ-20261004-003` 的 4 条散文）被漏报。我核 `7ae5c82` 的**最终实现**（`lint_card_dir` 内）：

```python
paths = _owned_paths(text)
if paths:
    path_claims.append((path.name, paths))
rejected = [entry for entry in owned if not _looks_like_path(entry)]   # 独立计算，不依赖 paths 是否为空
if rejected:
    findings += check_owned_files_nonpath([(path.name, rejected)])
```

**关键**：`rejected` 是**独立**算出的（对原始 `owned` 逐条取反），**与 `paths` 是否非空解耦**——即使一张卡同时有合法路径（走 `path_claims`）又有散文（走 `rejected`），散文仍被独立报出。实测佐证：`XJ-20261004-003` 既有 3 条合法路径（走 CONFLICT）又报出 4 条散文 NONPATH，**两条腿并行走通**，正是修正要堵的漏报场景。裁定：**修正正确且落地，漏报被堵住。**

### ② 形状判定的宽严 —— **接受（保守报 WARN，不猜归属，职责与 CONFLICT 分离）**
