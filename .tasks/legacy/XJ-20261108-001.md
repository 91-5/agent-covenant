- **D1（编译器 `tools/eval/dsl_compiler.py`）**：结构化断言记录解析器 + 验证器。
  - 输入：产物正本附带的 JSON（结构化记录列表，字段 = §12 D1 八字段）。
  - 解析：schema 校验（字段存在性/类型/枚举值）；predicate ∈ 冻结 9 值；claim_type ∈ 5 枚举；`evaluative` 不得携带 predicate；`verification_command` 与 `artifact_path` 二者必居其一（≤1 条命令）。
  - 执行：按 predicate 机械比对（`matches_regex` 限 Python re + 判定器 30s 超时罩；`exact_answer` = 验证命令输出与 expected 精确比对，语义等价路径不得实现）；`json_path_equals` 仅支持点分路径取值（不引入 jq 依赖）。
  - 输出：逐条 `{claim_id, observed, expected, predicate_ok, detail}`；失败样例全部留痕（与现行纪律一致）。
  - **零裁量**：编译器不含任何自然语言理解逻辑——它只解析结构化输入并机械执行 predicate。「编译」环节（自由文本 → 结构化记录）由被测执行者承担，编译质量就是影子试点要测的东西。
- **D2（影子对齐器 `tools/eval/shadow_align.py`）**：影子轨对齐与一致率度量。
  - 输入：主轨抽取结果（`extract.py` 的 `extract_claims` 输出）+ 编译器输出（D1）。
  - 对齐：按 `claim_id` ↔ 主轨断言条目逐条对齐（对齐规则冻结在本卡内：一对一对齐，多对一/一对多记缺口）。
